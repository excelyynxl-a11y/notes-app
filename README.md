# 📝 Note - Note-App

Note is a simple full-stack note-taking application built with the **MERN stack**. It supports secure authentication, clean and modern UI, creating personalised to-do-list with CRUD operation (create notes, read notes, update and pin notes, delete notes).

---

## 🚀 Features

- 🔐 **Authentication & Authorization**
  - JWT-based authentication

- 📝 **Note CRUD Operation**
  - Create notes, read notes, update and pin notes, delete notes with frontend-backend API integration

- 👤 **User Account**
  - Persistent user sessions

- 🎨 **Modern UI**
  - Styled with Tailwind CSS
  - Icons powered by Lucide React

---

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- Axios
- Lucide React

### Backend
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT (Authentication)
